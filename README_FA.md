# حسابداری شخصی — نسخهٔ اولیهٔ آزمایشی

رابط کاربری فارسی و راست‌چین. این پروژه برای ساخت APK آزمایشی از طریق GitHub Actions آماده شده است.

## قابلیت‌های پیاده‌سازی‌شده در این نسخه
- ثبت محلی درآمد و هزینه و ذخیره در SharedPreferences
- محاسبه مجموع درآمد، هزینه و مانده
- ثبت زمان دستگاه هنگام ذخیره تراکنش
- دفتر تراکنش‌ها
- نمودار ساده درآمد در برابر هزینه
- انتخاب تصویر از گوشی

## هنوز پیاده‌سازی نشده
- OCR فارسی و استخراج خودکار فاکتور/رسید
- اتصال واقعی به هوش مصنوعی و پرسش‌وپاسخ مالی
- مشتریان/تأمین‌کنندگان، چک‌ها، بدهی/طلب و سررسیدها
- خروجی PDF و چاپ، پشتیبان‌گیری و رمزگذاری تخصصی

این نسخه را به‌عنوان نمونهٔ اولیه آزمایش کن؛ برای داده‌های واقعی مالی مهم، تا زمان اضافه‌شدن پشتیبان‌گیری و کنترل‌های امنیتی به آن تکیه نکن.

## ساخت APK
1. همهٔ محتویات مخزن را در ریشهٔ مخزن GitHub قرار بده، نه در یک پوشهٔ اضافی.
2. تب Actions را باز کن.
3. گردش کاری Build Android APK را انتخاب کن و Run workflow را بزن.
4. پس از موفقیت، artifact با نام SmartFinance-APK را دانلود و استخراج کن.
